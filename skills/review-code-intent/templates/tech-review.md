## 테스트 관점

현재 테스트가 변경된 동작을 충분히 검증하는지.

특히 다음을 확인한다.

- 변경된 분기마다 테스트가 있는가
- **테스트가 존재하지만 실제 위험을 검증하지 못하는 경우** (mock이 과해 결함이 있어도 green인 경우 등)
- 정상 / 실패 / 경계값 3종이 갖춰졌는가

추가로 필요해 보이는 테스트 시나리오를 구체적으로 적는다.
