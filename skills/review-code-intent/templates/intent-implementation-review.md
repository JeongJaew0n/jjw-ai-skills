**실제 구현**
무엇이 되어 있는가. `path/To/File.java:123` — `ClassName.methodName`

**판정**
충족 / 부분 충족 / 미충족 / 과잉 / 판정 불가

**근거**
`실행 확인` / `코드 확정` / `미측정` 중 하나를 명시하고 그 내용을 쓴다.
충족 판정도 근거가 필요하다. "구현돼 있어 보인다"는 판정이 아니다.

**미달 내용**
부분 충족·미충족일 때 정확히 무엇이 빠졌는지. 충족이면 이 항목을 생략한다.

## 맥락 적합성

의도를 달성했는지와 별개로, **달성하는 방식**이 이 레포의 맥락에 맞는가.

- 유사 기능이 이미 있는데 다른 방식으로 다시 구현하지 않았는가
- 기존 계층 구조·아키텍처와 같은 방향인가
- 레포 규약 문서(`CLAUDE.md`, `AGENTS.md`, `.claude/skills/**`)와 어긋나지 않는가

어긋난 항목만 근거와 함께 쓴다. 취향 차이는 쓰지 않는다.

## 확인 필요

출처가 `추론` 인 항목 중 사람 확인이 필요한 것.

여기 있는 항목은 **미충족으로 단정하지 않는다.** 무엇을 확인하면 판정이 확정되는지 함께 적는다.
