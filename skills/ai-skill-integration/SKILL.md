# /ai-skill-integration — Claude 와 Codex 의 스킬을 맞춘다

## 이 스킬이 푸는 문제

같은 스킬이 두 에이전트에 따로 들어가 있으면 **어느 쪽이 최신인지 알 수 없는 상태**가 돼. 한쪽에서 고치고 다른 쪽을 잊으면, 다음에 그 스킬을 쓸 때 옛 버전이 돌아. 에러가 안 나니까 한참 뒤에야 알아채고.

이 저장소가 실제로 그 상태를 한 번 만들었어. `bin/install.sh` 가 **저장소 스킬**에 대해선 그걸 심링크로 풀었고, 이 스킬은 **저장소 밖 스킬** — 각 머신에만 있는 업무용 스킬들 — 을 맡아.

## 타협 불가 가드레일

- **방향은 반드시 사용자한테 물어.** 분석 결과가 한쪽으로 쏠려 보여도 알아서 정하지 마. 스킬은 사용자가 쓰는 도구고, 어느 쪽이 "맞는" 버전인지는 파일 시각이 아니라 사용자만 알아.
- **묻기 전에 분석 결과부터 보여줘.** 근거 없이 "어느 쪽으로 갈까요?" 하고 물으면 사용자가 판단할 재료가 없어.
- **지우지 마.** 한쪽에만 있는 스킬은 채우기만 해. 반대편에서 지우지 마.
- **덮어쓰기 전에 백업해.** 백업 경로는 사용자한테 알려줘.
- **저장소가 관리하는 스킬은 건드리지 마.** 그건 `bin/install.sh` 가 할 일이고, 심링크라 이미 양쪽이 같아.
- **계보가 다른 스킬은 자동 처리하지 마.** 아래 참조.

## 실행 절차

### 1. 분석 — 먼저 돌리고, 결과를 사용자한테 보여줘

```bash
"$SKILL_DIR/bin/skill-sync.py" analyze
```

`SKILL_DIR` 은 이 `SKILL.md` 가 있는 디렉터리야. 읽기 전용이라 아무것도 안 바꿔.

출력은 세 덩어리야.

| 덩어리 | 뜻 |
|---|---|
| 동기화가 필요한 스킬 | 한쪽에만 있거나 내용이 갈린 것. 상태·최신 쪽·양쪽 mtime |
| 집계 | `claude 가 최신 N개 / codex 가 최신 M개 / 이미 같음 K개` |
| 제외 | 저장소 관리 · 다른 패키지 · 계보 충돌 |

**전부 붙여넣지 말고, 사용자가 결정하는 데 필요한 것만 추려.** 집계 한 줄이랑, 쏠린 방향과 다른 예외 항목이 핵심이야.

### 2. 최신 판정이 어떻게 나오는지 알고 보고해

판정은 세 단계야.

1. **내용 해시** — 파일 경로랑 바이트를 합쳐서 sha256. 같으면 `동일` 로 끝. 심링크가 같은 원본을 가리켜도 `동일` 이야.
2. **최신 mtime** — 다르면 각 스킬 디렉터리에서 가장 최근에 수정된 파일의 시각을 비교해.
3. **내용 규모** — 2번 판정을 반증하는 보조 신호. 아래 참조.

**mtime 은 추정이지 사실이 아니야.** 복사·체크아웃·백업 복원이 시각을 바꾸고, 내용은 옛것인데 시각만 새것일 수도 있어. 그래서 이 스킬은 판정을 근거로만 쓰고 **결정은 사용자한테 넘겨.** 보고할 때 이 한계도 같이 말해.

#### 내용 규모가 mtime 을 반증한다

최신으로 판정된 쪽의 총 바이트가 반대쪽의 **60% 미만**이면 `!` 로 표시하고 의심 블록에 따로 뽑아.

mtime 은 새로운데 내용이 훨씬 작으면, 그건 갱신이 아니라 **래퍼 껍데기거나 잘린 사본**일 가능성이 높아. 실제로 그런 일이 있었어.

```
meeting-minutes
  claude  6파일 29880B   2026-02-26   ← 본체 (references/ + scripts/ 포함)
  codex   2파일  1470B   2026-07-09   ← "# Codex wrapper for meeting-minutes"
```

mtime 만 보면 codex 가 4개월 더 최신이야. 그대로 밀었으면 **24줄 래퍼가 400줄 본체를 덮었을 거야.** 규모가 5% 라는 사실이 그걸 막았어.

**의심 항목은 방향을 정하기 전에 내용을 직접 열어 확인해.** 규모도 신호일 뿐이야 — 정당하게 줄어든 리팩터링일 수도 있어. 방향을 자동으로 뒤집지 마.

### 3. 방향을 물어 — 생략 금지

`AskUserQuestion` 으로 물어. 선택지는 둘이야.

| 선택지 | 하는 일 |
|---|---|
| `claude → codex` | Claude 쪽을 원본으로 삼아 Codex 를 맞춘다 |
| `codex → claude` | Codex 쪽을 원본으로 삼아 Claude 를 맞춘다 |

**집계가 갈리면 그 사실을 질문에 담아.** 예를 들어 `claude 가 최신 21개 / codex 가 최신 1개` 면, 한 방향으로 밀 때 그 1개가 옛 버전으로 덮인다는 걸 알려줘. 그 1개의 이름도 같이 보여주고.

쏠린 쪽으로 밀되 예외만 따로 처리하고 싶다는 답이 오면 `--only` 로 나눠서 두 번 돌려.

```bash
"$SKILL_DIR/bin/skill-sync.py" apply --direction claude-to-codex
"$SKILL_DIR/bin/skill-sync.py" apply --direction codex-to-claude --only meeting-minutes
```

### 4. 적용

```bash
"$SKILL_DIR/bin/skill-sync.py" apply --direction <고른 방향> [--only a,b,c]
```

스크립트가 하는 일:

- 덮어쓸 대상이 있으면 먼저 `~/.claude/backups/skill-sync-<타임스탬프>/` 에 복사해
- 원본 쪽에 없는 스킬은 **건너뛰어.** 그 방향으로는 채울 수 없다는 뜻이고, 반대편에서 지우지 않아
- 심링크는 따라가서 **실체를 복사해.** 대상 머신에 없는 경로를 가리키는 링크를 안 만들려고

### 5. 검증하고 보고해

적용한 다음 다시 분석해서 남은 차이를 확인해.

```bash
"$SKILL_DIR/bin/skill-sync.py" analyze
```

보고할 것 — 방향, 적용·건너뜀 개수, 백업 경로, **남은 차이**(있으면 왜 남았는지). 그리고 **새 스킬은 다음 세션부터 로드된다**는 것도 알려줘.

## 제외되는 세 부류

### 저장소 관리

`~/my/Dev/jjw-ai-skills/skills/` 에 있는 이름은 건드리지 마. 이미 양쪽이 같은 저장소를 가리키는 심링크고, 갱신은 `git pull` 이랑 `bin/install.sh` 가 해. 여기서 복사하면 **심링크가 실체로 바뀌면서 드리프트가 다시 생겨.**

### 다른 패키지

description 이 `[OMX]` 로 시작하면 oh-my-codex 가 설치한 거야. 그 패키지가 관리하니까 여기서 옮기지 마.

### 계보 충돌 — 같은 이름, 다른 출처

**한쪽만 `[OMX]` 인 경우야.** 이름이 같아서 동기화 대상처럼 보이지만 실제로는 서로 다른 스킬이야. 어느 방향으로 밀어도 한쪽이 사라져.

실제 사례 — `configure-notifications`

| 쪽 | 정체 |
|---|---|
| Claude | 개인 스킬. Discord·Telegram·Slack 웹훅을 세션 훅에 연결 |
| Codex | `[OMX] Configure OMX notifications` — 다른 패키지의 것 |

**자동으로 처리하지 마.** 사람이 한쪽 이름을 바꾸든 한쪽을 버리든 정해야 해. 스크립트는 이 부류를 `**` 로 표시하고 이유를 같이 출력해.

## 동작 원칙

- **mtime 으로 단정하지 마.** 판정 근거일 뿐이야. "codex 가 최신" 이라고는 보고하되 "그러니까 codex 가 맞다" 고 쓰진 마.
- **`!` 가 붙은 항목은 꼭 내용을 열어봐.** 규모가 크게 줄어든 쪽을 원본으로 삼는 건 대개 사고야. `apply` 도 그 방향이면 경고는 띄우지만 막지는 않아 — 정당한 축소일 수 있으니까.
- **한 방향으로 미는 게 기본이지만 강제는 아니야.** 예외가 한두 개면 `--only` 로 나눠 도는 게 나아. 21개 맞추자고 1개를 잃을 이유는 없어.
- **적용한 다음엔 꼭 다시 분석해.** 스크립트가 "적용 N개" 라고 말한 거랑 실제로 같아진 건 별개야.
- **양쪽 디렉터리가 다 있어야 해.** `~/.codex/skills` 가 없으면 Codex 를 안 쓰는 머신이니까, 만들지 말고 그 사실을 알리고 멈춰.
- **이 스킬은 커밋 안 해.** 대상이 전부 `~/` 아래, 저장소 밖이야.

## 참고: 스크립트 인터페이스

```
skill-sync.py analyze [--json]
skill-sync.py apply --direction claude-to-codex|codex-to-claude [--only a,b,c]
```

`--json` 은 분류 결과를 그대로 줘 — `state`, `newer`, `suspect`, `excluded`, 그리고 양쪽의 `*_mtime` / `*_bytes` / `*_files`. 사용자한테 표를 다르게 그려주고 싶을 때 써.
