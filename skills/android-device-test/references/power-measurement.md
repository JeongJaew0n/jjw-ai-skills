# 배터리 카운터로 전력 재기

> 실측 출처: Galaxy S23+ / Android 16, 무선 adb. 화면을 덮는 앱의 소모를 재다가 두 번 실패하고
> 세 번째에 성공한 절차. 앱 이름은 뺐다.

외부 전력계 없이 폰 하나로 "이 기능이 배터리를 얼마나 먹나" 를 재는 방법이다. 결론부터:
**USB 를 빼고, 조건당 30분, 상태 검증에 실패하면 즉시 중단.**

## 안 되는 방법

| 방법 | 왜 안 되나 |
|---|---|
| `dumpsys battery unplug` | 프레임워크가 방전 중이라고 **인식만** 한다. 케이블이 꽂혀 있으면 하드웨어는 계속 충전해 카운터가 오히려 오른다. 충전 중에는 원리적으로 못 잰다 |
| `/sys/class/power_supply/battery/current_now` | 권한이 없어 안 읽힌다 |
| 정수 퍼센트(`level`) | 해상도가 1% ≈ 수십 mAh 라 몇 시간을 재야 한다 |

## 되는 방법: `Charge counter`

`dumpsys battery` 의 `Charge counter` 는 µAh 단위 쿨롱 카운터다. `android-device.py state` 가 같이 보여 준다.

**해상도 함정**: 값이 매끄럽게 줄지 않고 **기기 고유의 눈금 단위로만 뛴다.** S23+ 에서는 8750 µAh 였다. 화면을 켜고 전류를 쓰는 중에도 60초간 값이 그대로였다.

- 3분 측정에서 눈금 하나는 175 mA 다. 3분은 측정이 아니라 양자화 잡음이다.
- **조건당 최소 30분**을 재야 눈금이 10개쯤 쌓여 오차가 10% 안으로 들어온다.
- 결과에는 **눈금 개수를 함께 적는다.** 눈금이 적으면 그 값은 믿지 않는다.
- 눈금 단위는 기기마다 다르다. 먼저 몇 분 동안 값을 찍어 보고 최소 변화량을 확인한다.

카운터 자체를 믿어도 되는지 교차 검증하는 방법이 있다. 퍼센트와 카운터로 완충 용량을 역산해서 기기 사양과 맞는지 본다. S23+ 에서는 약 4.2~4.5 Ah 가 나와 사양(4.7 Ah)과 맞았다.

## 절차

1. 무선 adb 로 바꾼다. 연결을 바꾸는 일이라 사용자 확인을 받는다.
2. **USB 케이블을 물리적으로 뺀다.**
3. 폰 잠금을 풀고, `screen_off_timeout` 을 측정 시간보다 길게 둔다. 그 전에 `snapshot` 을 찍는다.
4. 조건마다 시작 시점에 상태를 **검증하고, 어긋나면 즉시 중단한다.**
   - 검증할 것: 잠금 화면이 아닌지, 측정 대상 창·서비스가 실제로 떠 있는지, 기대한 화면 상태(`mWakefulness`)인지
   - 로그만 남기고 계속 가면 30분을 버린다. 실제로 폰이 잠겨 있어 기능이 켜지지도 않은 채 30분을 쟀다. 탭이 잠금 화면에 떨어졌다.
5. 5분마다 상태를 다시 본다. 대기는 **호스트에서** 한다.
   - 화면이 꺼지면 기기가 딥슬립에 들어가 `adb shell sleep` 이 멈춘다.
   - 읽기에는 재연결 재시도를 넣는다.
6. 끝나면 `restore` 로 원복하고 `diff` 로 확인한다. 아래 두 가지도 확인한다(배터리를 많이 쓰면 바뀐다).
   - 절전 모드: `settings get global low_power`
   - 주사율: `dumpsys display | grep primary=physical`

## 조건 설계

비교의 기준선과 하한선을 함께 잰다.

| | 조건 |
|---|---|
| 기준선 | 화면 켜짐(런처) |
| 대상 | 재고 싶은 기능 상태들 |
| 하한선 | 실제 화면 꺼짐 |

- **화면을 끄는 조건은 맨 마지막에** 둔다. 화면을 끄면 잠기고, 잠금은 adb 로 못 푼다.
- 하한선은 무선 adb 와 주기적인 상태 읽기 때문에 깊은 절전에 못 들어가 실제보다 높게 나온다. **상한**으로 읽는다.

## 실측 예 (S23+, 조건당 30분)

| 조건 | 평균 전류 | 눈금 |
|---|---|---|
| 화면 켜짐(런처) | 209.5 mA | 12.0 |
| 전면 검정 오버레이 + 글자 몇 개(패널 밝기 0.30) | 183.3 mA | 10.5 |
| 전면 검정 오버레이, 표시 없음(패널 밝기 0) | 183.3 mA | 10.5 |
| 실제 화면 꺼짐 | 96.1 mA (상한) | 5.5 |

이 표에서 읽을 것은 두 가지다.
- 검은 화면을 그리는 비용의 대부분은 켜진 픽셀이 아니라 **화면이 켜져 있다는 사실**(SoC·디스플레이 파이프라인·터치)에서 나온다. AMOLED 에서 패널 밝기 0.30 과 0 은 30분 해상도(17.5 mA) 안에서 구분되지 않았다.
- 계산식: 평균 mA = Δ카운터(µAh) × 3.6 / 초.
