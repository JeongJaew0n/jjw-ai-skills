## 왜 이걸 지금 하는가
- 전역 지침(`~/.claude/CLAUDE.md` 9절)이 "문서·매뉴얼처럼 말하지 말고, 친한 선배 개발자처럼
  설명하라" 고 정해 두었다. 스킬 본문은 대부분 `~한다` 문어체 규정집 형태라 그 지침과 어긋난다.
- `ai-plan-docs` 하나만 대화체라 저장소 안에서 문체가 갈라졌다.

## 결정된 방향
본문만 대화체로 바꾸고, frontmatter·코드 블록·산출물 템플릿은 건드리지 않는다.

## 기각된 대안
- 파일 전체(템플릿·references·리뷰 기록 포함) 일괄 변환 — 스킬이 생성하는 산출물 문체까지 바뀌어
  동작 변경이 되고, 과거 기록의 원문이 사라진다
- description 도 대화체로 — AGENTS.md 가 형식을 정해 두었고, 트리거 문구 변경은 호출 동작에 영향
- 스크립트(sed)로 어미만 치환 — 한국어 어미는 문맥 따라 활용이 달라 기계 치환이 문장을 깨뜨린다.
  사람이 읽는 수준으로 파일마다 다시 쓴다

## 제약 / 합의 사항
